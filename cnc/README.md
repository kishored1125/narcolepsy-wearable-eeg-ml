# CNC PSG

This folder contains outputs for the external PSG narcolepsy/control experiment.

CNC was used as a supporting external experiment because it contains PSG EDF recordings with sleep-stage annotations and narcolepsy/control labels. It was not treated as the main wearable EEG result because the recording device, montage and cohort structure differ from the Narcolepsy Revolution Dreem data.

## Contents

- `outputs/edf_outputs/`: processed CNC EDF feature tables and extraction summaries.
- `outputs/evaluation_outputs/`: CNC model metrics, cross-validated predictions and feature-importance outputs.
