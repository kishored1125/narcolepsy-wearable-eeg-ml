# Final Results

This folder contains consolidated tables, figures and audit documents assembled from the project outputs.

## Contents

- `outputs/tables/`: final model metrics, dataset comparison tables, feature-family summaries and validation audits.
- `outputs/figures/`: final figures used for model comparison, confusion matrices, feature importance and methodology.
- `outputs/model_audits/`: updated figures and tables for the Narcolepsy Revolution, NRev-vs-SSP and feature-importance analyses.
- `outputs/docs/`: concise implementation and validation summaries.

These files are the most useful outputs for checking the analysis results without rerunning the full raw-data pipelines.
