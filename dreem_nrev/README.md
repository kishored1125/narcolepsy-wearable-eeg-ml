# Dreem Narcolepsy Revolution

This folder contains outputs for the main Narcolepsy Revolution analysis.

## Contents

- `outputs/loading_outputs/`: diagnosis mapping, report record table and extraction summaries.
- `outputs/feature_outputs/`: report-only, H5-only and combined subject-level feature tables.
- `outputs/eda_outputs/`: cohort, demographic and sleep-architecture exploratory outputs.
- `outputs/model_outputs/`: main model metrics and fold-level evaluation tables.
- `outputs/evaluation_outputs/`: confusion matrices and feature-importance figures/tables.
- `outputs/quality_control_outputs/`: missingness, failed-record and feature-completeness checks.
- `outputs/error_analysis_outputs/`: subject-level prediction and misclassification summaries.
- `improvements/`: stage-level, subtype, channel-strategy, hyperparameter tuning and advanced-feature experiment outputs.

The primary modelling task is narcolepsy versus other hypersomnia at subject level.
