# PhysioNet Sleep-EDF

This folder contains the public reference workflow outputs.

PhysioNet Sleep-EDF was used to validate EDF loading, hypnogram alignment, 30-second epoch processing and sleep-stage classification. It was not used as a narcolepsy diagnostic dataset.

## Contents

- `outputs/loading_outputs/`: discovered PSG/hypnogram recording pairs.
- `outputs/feature_outputs/`: extracted epoch-level sleep-stage features.
- `outputs/eda_outputs/`: sleep-stage distribution and band-power summaries.
- `outputs/model_outputs/`: sleep-stage classification metrics.
- `outputs/evaluation_outputs/`: confusion matrix and feature-importance outputs.
- `outputs/edf_sample_outputs/`: small EDF inspection figures and tables.
