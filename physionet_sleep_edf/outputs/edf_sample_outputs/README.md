# Real EDF Sample Inspection Outputs

This folder contains real Sleep-EDF PhysioNet EDF inspection outputs for 4 recordings: SC4001E0, SC4002E0, SC4011E0, SC4012E0.

Generated outputs include channel metadata, hypnogram annotation samples, raw EEG signal snippets, 30-second epoch feature samples and per-recording plots.

Use these files to show what EDF data looks like before and after processing.
