# Simons Sleep Project

This folder contains outputs for the same-device external comparison.

The Simons Sleep Project data were used as a Dreem-recorded healthy/control comparison for the Narcolepsy Revolution cohort. The main comparison used common sleep-report and sleep-architecture features rather than unrestricted raw dataset merging.

## Contents

- `outputs/report_outputs/`: SSP report-derived record and subject features.
- `outputs/comparison_outputs/`: Narcolepsy Revolution versus SSP model outputs.
- `outputs/edf_outputs_50x2/`: supporting SSP EDF extraction outputs from 50 controls with two nights each.
